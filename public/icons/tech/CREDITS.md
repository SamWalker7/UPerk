Source: [Simple Icons](https://simpleicons.org) (CC0 — free for commercial
use, no attribution required). Fetched via `cdn.simpleicons.org/{slug}/{hex}`
using each brand's own color.

`typescript.svg`, `nextdotjs.svg`, `tailwindcss.svg`, `postgresql.svg`,
`graphql.svg`, `googlecloud.svg`, `kubernetes.svg`, `docker.svg`,
`githubactions.svg`, `apple.svg`, `android.svg`, `figma.svg`, `sketch.svg`,
`framer.svg`.

**No Azure icon** — Simple Icons doesn't carry one (Microsoft's brand
guidelines restrict unlicensed use of the Azure mark), so Azure is listed as
a text-only chip on the landing page instead of a logo.
