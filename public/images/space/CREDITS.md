# Space background images — source & licensing

Both images are **NASA public domain** — free for commercial use, no
attribution legally required, no license fee. Downloaded 2026-09-13 via the
public NASA image API (`images-api.nasa.gov`).

| File | NASA ID | Subject | Source |
|---|---|---|---|
| `deep-field.jpg` | PIA12110 | Hubble Deep Field — galaxies against deep space | https://images-assets.nasa.gov/image/PIA12110/PIA12110~medium.jpg |
| `nebula.jpg` | PIA13044 | IC 1795 nebula | https://images-assets.nasa.gov/image/PIA13044/PIA13044~medium.jpg |

Both were downscaled and recompressed for web (JPEG quality ~45) — 228 KB and
114 KB respectively, down from the originals.

**One caveat to be aware of:** NASA's media guidelines say its imagery generally
can't be used in a way that implies NASA *endorses* a commercial product or
service. Using these purely as decorative background texture is fine. Don't
pair them with copy that suggests NASA is a client or partner.
